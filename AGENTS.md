# Agent guide

This is the operating guide for AI agents using this project
It is structured following a progressive disclosure approach, see [A Complete Guide to Agents.MD - Matt Pocock](https://www.aihero.dev/a-complete-guide-to-agents-md) for more info.
Follow the links in the Documentation section for guidance with any project specifics.

## Project Configuration

This is a React Native project with [Expo SDK 57](https://docs.expo.dev/versions/v57.0.0/)
All new code must be based on the APIs that are available in this version of the SDK.
